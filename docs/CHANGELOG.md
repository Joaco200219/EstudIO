# Version 1.0.0 (2026-07-11)
Esta es la primera versión de EstudIO que no es una version de prueba. De las versiones anteriores se llegan las siguientes funcionalidades ya testeadas:
- Capacidad de crear apuntes, formatear el texto e inclusive resaltarlo.
- Capacidad de agregar imágenes mediante CTRL+V o seleccionando desde el explorador de archivos.
- Capacidad de crear recordatorios que se muestran en la barra lateral si la fecha de recordatorio es la fecha del dia actual.

# Versión 1.0.1 (BETA) (2026-08-05)
Esta versión marca el inicio de la beta de EstudIO. De versiones anteriores se mantienen las siguientes funcionalidades ya probadas:
- Capacidad de crear apuntes, formatear el texto e incluso resaltarlo.
- Capacidad de agregar imágenes mediante **Ctrl+V** o seleccionándolas desde el explorador de archivos.
- Capacidad de crear recordatorios que se muestran en la barra lateral cuando la fecha del recordatorio coincide con el día actual.

Novedades añadidas en esta versión:
- **Compartir/exportar apuntes como PDF (solo lectura)**.
- **Compartir/exportar apuntes como ZIP (permite modificar los apuntes)**.
  - La app **solo acepta archivos ZIP generados por la propia aplicación** para volver a leer/importar apuntes.
- **Tabla en el editor de texto**: se incorporó la herramienta para crear tablas.
